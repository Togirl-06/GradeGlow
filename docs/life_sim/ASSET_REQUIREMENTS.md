# Assets and licensing

Current build uses **no third-party art**. Avatars, buildings, props and emoji icons are drawn in code
(`ui/painters/`); emoji render from the system font (check platform licensing if bundling a font).
If a future 3D renderer is adopted: prefer CC0/commercial-licensed modular packs, record each
pack's license here, keep polygon budgets mobile-friendly, and use LODs.

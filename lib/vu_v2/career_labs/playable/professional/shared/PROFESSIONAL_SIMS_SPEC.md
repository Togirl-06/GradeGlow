# Professional Business Simulations Spec

**Business ≠ Finance ≠ Accounting ≠ Marketing ≠ Economics.**

Shared engine: `playable/professional/shared/`

Loop: **Briefing → Investigate → Decide → Run simulation → Consequences → AI review → Unlock**

## Rules

- Simulation is the lesson. Decision is the assessment. Consequence is the feedback.
- Never substitute a generic quiz page.
- Score professional skills, not only correctness.
- One reusable hub + case store; distinct worlds per career.
